# livelooper presets / Presets

**English** – Ready-to-play livelooper sets. A `.livelooper` file holds a complete looper – loops (lossless FLAC), effects, rhythm, scenes and tempo – in one file.

| File | What's inside |
|---|---|
| `demo-set.livelooper` | The demo set of the first start: groove at 100 BPM (Studio kit), bass, keys and arpeggio on tracks 1 – 3, scene 1 = bass + keys, scene 2 = everything. Self-made loops, CC0. |

**Open a set**: download the file, then in livelooper *SETUP → Load set …* – or drag it onto the livelooper window.

**Share your own**:
1. In livelooper: *SETUP → Save set to share (.livelooper, one file with all audio) …*
2. Check that every sound in the set is yours or may be shared freely (no samples from commercial libraries or records).
3. Open a pull request that adds the file to this folder with one line in the table above (name, tempo, what's inside, license – CC0 or CC BY 4.0 recommended), or attach it to an issue.

Inside, a `.livelooper` file is a normal ZIP archive: `set.xml` (settings), `audio/trackN.flac` (loops), `info.json` (tempo, livelooper version) and `README.txt`. MIDI mapping, keyboard mapping and audio routing stay on the computer and are not part of a set.

---

**Deutsch** – Spielfertige livelooper-Sets. Eine `.livelooper`-Datei enthält einen kompletten Looper – Loops (verlustfrei als FLAC), Effekte, Rhythmus, Szenen und Tempo – in einer Datei.

| Datei | Inhalt |
|---|---|
| `demo-set.livelooper` | Das Demo-Set des ersten Starts: Groove mit 100 BPM (Studio-Kit), Bass, Keys und Arpeggio auf den Spuren 1 – 3, Szene 1 = Bass + Keys, Szene 2 = alles. Selbst erzeugte Loops, CC0. |

**Set öffnen**: Datei herunterladen, dann in livelooper *SETUP → Set laden …* – oder auf das livelooper-Fenster ziehen.

**Eigene Sets teilen**:
1. In livelooper: *SETUP → Set zum Teilen speichern (.livelooper, eine Datei mit allem Audio) …*
2. Prüfen, dass jeder Klang im Set von dir ist oder frei geteilt werden darf (keine Samples aus kommerziellen Libraries oder von Platten).
3. Einen Pull Request öffnen, der die Datei in diesen Ordner legt und eine Zeile in der Tabelle oben ergänzt (Name, Tempo, Inhalt, Lizenz – empfohlen CC0 oder CC BY 4.0), oder die Datei an ein Issue hängen.

Innen ist eine `.livelooper`-Datei ein normales ZIP-Archiv: `set.xml` (Einstellungen), `audio/trackN.flac` (Loops), `info.json` (Tempo, livelooper-Version) und `README.txt`. MIDI-Mapping, Tastatur-Mapping und Audio-Routing bleiben auf dem Rechner und gehören nicht zum Set.
