Before you start

Unsigned software: livelooper is not (yet) signed with an Apple Developer ID. macOS therefore blocks the first start. Open System Settings → Privacy & Security, scroll to Security and click Open Anyway - once. This installer already removes the download quarantine from the installed app and plug-ins.

Microphone: on the first start the app asks for access to the microphone / audio input. Allow it - livelooper needs it to record. If macOS keeps asking or recording stays silent: tccutil reset Microphone com.groovex.livelooper in Terminal, then start livelooper again.

Plug-ins: after installing, let your DAW rescan its plug-ins. The Audio Unit cache is refreshed by the installer.

Help: in livelooper press ? (top right) - every function explained.
